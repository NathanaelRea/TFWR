# The Farmer Was Replaced Docs

This folder is a workspace-local reference set for building and optimizing scripts in this save, with extra focus on `leader_reset.py`.

## What To Trust

Use sources in this order when they disagree:

1. Local workspace files:
   - `__builtins__.py` for current names, signatures, enums, and most behavior notes.
   - `save.json` for what this specific save has unlocked and what items it currently holds.
   - local strategy files such as `leader_reset.py`, `sunflower.md`, and `leaderboard.md`.
2. Recent wiki pages on `thefarmerwasreplaced.wiki.gg`, especially:
   - Plant growth
   - Execution Details
   - Operation Costs
   - Entities
   - Items
   - Unlocks
   - Unlocks Data
   - Mazes
   - Dinosaurs
3. Older wiki pages only when nothing better exists. Several older pages still use removed seed/trade names or stale leaderboard targets.

## Start Here

- `leader-reset.md`: current reset route, phase gates, and optimization targets.
- `progression-and-unlocks.md`: dependency order and full unlock cost tables.
- `mechanics-and-api.md`: tick economics, speed scaling, and builtin behavior.
- `entities-and-growth.md`: crop/system mechanics, growth stats, and special rules.
- `sunflowers.md`: sunflower-specific notes and source conflicts.
- `leaderboards.md`: current leaderboard targets and run semantics.
- `save-state.md`: current inventory and unlocked capability snapshot for this save.

## Why This Exists

The wiki is useful, but not fully consistent across versions. These docs consolidate:

- current local enum/function names,
- recent numeric wiki pages,
- current save unlock state,
- and the repo's own leaderboard/reset assumptions.
